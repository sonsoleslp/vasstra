# Descriptive Statistics per State

Summarises each clustering indicator within each state, the numeric
companion to `plot(x, which = "states", type = "variables")`. By default
the indicators are pooled over time; `by_time = TRUE` reports one block
per time point.

## Usage

``` r
state_descriptives(x, ...)

# S3 method for class 'vasstra_states'
state_descriptives(
  x,
  scale = c("standardized", "original"),
  by_time = FALSE,
  ...
)

# S3 method for class 'vasstra'
state_descriptives(x, ...)
```

## Arguments

- x:

  A `vasstra` or `vasstra_states` object.

- ...:

  Not used.

- scale:

  Indicator scale: `"standardized"` (default, the scale the states were
  clustered on) or `"original"` (the raw indicators, where a trailing
  `"_z"` resolves to its untransformed column).

- by_time:

  Break the summary down per time point (`TRUE`) or pool over time
  (`FALSE`, default).

## Value

A tidy data frame with one row per state and indicator (and time point
when `by_time = TRUE`): the grouping columns followed by `n`, `mean`,
`sd`, `median`, `min`, and `max`. States are ordered by the fit's state
order and indicators by their clustering order.

## See also

[`plot.vasstra_states()`](https://sonsoles.me/vasstra/reference/plot.vasstra_states.md)
with `type = "variables"` for the matching boxplots.
